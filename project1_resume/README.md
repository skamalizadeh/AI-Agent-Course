# پروژه ۱: عامل رزومه‌ساز

این پروژه یک عامل گفت‌وگومحور برای ساخت رزومه است. کاربر اطلاعاتش را می‌گوید، عامل داده‌ها را در مدل ساختاریافته ذخیره می‌کند، کمبودها را می‌پرسد، متن‌ها را بهبود می‌دهد و در پایان فایل‌های Word/PDF فارسی یا انگلیسی می‌سازد.

## ساختار فایل‌ها

| فایل | نقش |
|---|---|
| `config.py` | خواندن تنظیمات مدل از `.env` |
| `llm.py` | کلاینت مدل زبانی با retry |
| `resume_model.py` | مدل دادهٔ رزومه با Pydantic |
| `prompts.py` | پرامپت سیستمی عامل |
| `tools.py` | ابزارهای عامل: ذخیره، کمبودها، نمایش، بهبود متن، ساخت فایل |
| `improve.py` | الگوی بازتاب برای بهبود متن |
| `docx_builder.py` | ساخت Word فارسی/انگلیسی |
| `pdf_export.py` | تبدیل Word به PDF |
| `agent.py` | حلقهٔ عامل و اجرای ترمینالی |
| `app.py` | رابط وب Gradio |

## پیش‌نیاز

1. Python 3.10+  
2. نصب وابستگی‌ها از ریشهٔ مخزن:

```bash
pip install -r ../requirements.txt
```

3. ساخت فایل `.env` در ریشهٔ مخزن (یا کپی `.env.example` همین پوشه) و تنظیم مدل:

```env
LLM_BASE_URL=http://localhost:11434/v1
LLM_API_KEY=ollama
LLM_MODEL=qwen2.5:3b
```

برای OpenRouter یا ارائه‌دهنده‌های سازگار دیگر، همان سه مقدار را تغییر دهید.

## اجرا

### رابط وب (پیشنهادی)

```bash
cd project1_resume
python app.py
```

سپس نشانی نمایش‌داده‌شده در ترمینال (معمولاً `http://127.0.0.1:7860`) را باز کنید.

### ترمینال

```bash
cd project1_resume
python agent.py
```

## خروجی‌ها

فایل‌ها در پوشهٔ `output/` در ریشهٔ مخزن ساخته می‌شوند:

- `resume.json`
- `resume_fa.docx` / `resume_fa.pdf`
- `resume_en.docx` / `resume_en.pdf`

ساخت PDF در ویندوز/مک با Word یا در همهٔ سیستم‌ها با LibreOffice انجام می‌شود. اگر هیچ‌کدام نصب نباشد، فایل Word ساخته می‌شود.
